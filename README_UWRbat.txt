UnityWeightReduction.batのREADMEです

・機能
Unityのプロジェクトファイルから起動時に生成されるファイル&VisualStudio関連ファイルを削除することで容量を削減し、軽量化を図ります。

・使い方
プロジェクトのルートディレクトリ（Assetsフォルダと同じ階層）にbatファイルを置き、実行してください。

・消されるフォルダ
// Unity
Library
Logs
obj
Temp

// VS
.vs
.vscode

・消されるVS関連ファイル
.vsconfig
*.vsproj
*.sln
*.suo
*.pdb
*.user

・消したくないフォルダ、ファイルが含まれている場合
batをテキストエディタで開き、対象の部分のみ削除することで使えます。

・その他の軽量化方法
Assetsフォルダ内で使っていないファイルを適宜削除することで、軽量化できる場合があります。
各自の判断でお願いします。

・注意事項
フォルダの削除は自己責任で行ってください。
